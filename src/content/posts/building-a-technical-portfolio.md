A technical portfolio is more than a visual resume. It is a place where your projects, writing, and learning process can compound over time.

For this site, the strategy is simple:

- Write about practical technical problems.
- Show projects with context, tradeoffs, and outcomes.
- Share each article on LinkedIn to bring readers back to the website.
- Keep the GitHub repository public so people can also see the engineering behind the site.

This creates a loop: LinkedIn helps people discover the work, the website organizes the knowledge, and GitHub provides technical credibility.
